# Leyendas Merino: Batalla de Reinos

MOBA 5v5 en el navegador (móvil y escritorio). Partidas contra bots.

## Jugar

Abre: **https://kiampo007.github.io/leyendas-merino/**

1. Toca la pantalla de inicio.
2. Pulsa **Jugar**.
3. Elige héroe, dificultad y emblema.
4. Destruye el nexo enemigo.

### Controles

- **Celular:** joystick a la izquierda, habilidades a la derecha.
- **Computadora:** WASD o clic para mover. Q / E / R habilidades. B retorno. F tienda. P pausa. Tab marcador.

Gratis en GitHub Pages. No necesita cuenta ni servidor.
